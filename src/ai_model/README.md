# AI Models
Machine learning models for energy forecasting and fault diagnosis.

## Planned Models
- Solar generation forecasting (PVDAQ + NSRDB + NASA POWER)
- Wind power prediction (NREL WIND Toolkit + GEFCom)
- Turbine fault classification (SCADA data)
- Grounding/faithfulness evaluation model
- Lightweight domain adapters (LoRA)

> Training scripts and evaluation notebooks will be added in Phase-II.
