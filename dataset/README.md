# Dataset Details
Five dataset categories spanning the energy sub-domains GreenRAG serves.

| # | Dataset | Source | Size |
|---|---------|--------|------|
| 1 | Solar Forecasting (PVDAQ + NSRDB + NASA POWER) | NREL, NASA | ~2-5 GB/site-year |
| 2 | Wind Forecasting (NREL WIND Toolkit + GEFCom 2014) | NREL, IEEE | ~1 TB full / ~50 MB competition |
| 3 | Fault Diagnosis (Wind Turbine SCADA + PVDAQ Faults) | Open repos, NREL | ~200-500 MB |
| 4 | RAG Knowledge (IEC + NREL Reports + OEM Manuals) | IEC, NREL, OEMs | ~100-300 MB |
| 5 | Weather Reanalysis (ERA5 + NASA POWER) | ECMWF, NASA | ~1-10 GB/region-year |

> Full preprocessing details are documented in the Phase-I report.
